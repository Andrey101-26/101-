# VoSo

VoSo («Восо») — короткие выпуски с практическими советами. Откройте выпуск, чтобы прочитать текст или запустить запись. Ссылки «Следующий выпуск» и «Предыдущий выпуск» позволяют листать ленту. Инструкции по настройке скринридеров доступны на главной.

[Публичная версия на GitHub Pages](https://andrey101-26.github.io/101-/) показывает ленту и инструкции. После правки текста, шаблона или записи пересоберите страницы командой `python app.py --build-static` и добавьте обновлённые файлы в коммит.

Записи запускаются вручную. Сайт учитывает светлую, тёмную и принудительную цветовую схему системы.

Ссылка «Продолжить без настройки диктора» ведёт к ленте.

## Записать свой голос

На страницах вступления и выпусков есть готовые тексты. Запишите каждый текст отдельным файлом. Подойдут MP3, M4A и WAV. Например, для MP3 используйте такие имена:

- `audio/intro.mp3` — вступление.
- `audio/etiketka.mp3` — «Прочитать мелкую надпись».
- `audio/windows-tab.mp3` — «Перейти к нужной ссылке без мыши».
- `audio/iphone-gesture.mp3` — «Открыть выбранный пункт с VoiceOver».

Храните по одному авторскому файлу на выпуск. Пока авторская запись для первого выпуска отсутствует, на странице доступен синтетический образец с подписью.

## Запуск прототипа

1. Запустите `python app.py` в папке проекта. Подойдёт Python 3.10 или новее, устанавливать библиотеки не нужно.
2. Откройте [127.0.0.1:8000](http://127.0.0.1:8000/).

Python обрабатывает поиск в локальном режиме и формирует HTML. Браузеру нужны HTML и CSS. Для публикации с серверным поиском нужен хостинг с Python.

## Сценарий для проверки

На телефоне с уже включённым VoiceOver или TalkBack откройте сайт. Найдите ссылку «Как включить Экранный диктор в Windows». Откройте инструкцию и выполните шаги на компьютере. Проверьте, что компьютер начал озвучивать элементы и что клавиша Tab переводит фокус к следующей ссылке. Для проверки поиска введите «как включить экранный диктор» и откройте результат.

На компьютере с работающим скринридером проверьте ссылку пропуска в начало основного содержимого, переходы по заголовкам и ссылки на справку производителя. Соответствие WCAG и удобство прохождения сценария требуют отдельной проверки со скринридерами и с незрячими участниками.
