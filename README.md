# Голос и звук

Студенческий проект доступного сайта для незрячих и слабовидящих людей. На одной странице собраны поиск по каталогу, пошаговые уроки и демонстрационная форма запроса волонтёрам.

## Запуск

Откройте `index.html` в браузере. Для теста микрофона откройте сайт через локальный HTTP-сервер или HTTPS. Например, если установлен Python, выполните в папке проекта `python -m http.server 8000` и откройте [localhost:8000](http://localhost:8000/). Доступность голосового ввода зависит от браузера и разрешений на микрофон. Озвучивание использует синтез речи браузера.

## Исходники

- `index.html` — разделы, учебные материалы и форма.
- `styles.css` — адаптивная вёрстка, контрастные темы и видимый фокус.
- `app.js` — поиск, настройки, голосовой ввод, озвучивание и локальная проверка формы.

Каталог содержит учебные примеры. Форма принимает текст или фото для демонстрации. Отправка волонтёрам и серверная часть пока отсутствуют.

## Проверка перед защитой

1. Нажмите Tab сразу после открытия и активируйте ссылку «Перейти к основному содержимому». Продолжите работу через Tab, Shift + Tab, Enter и пробел.
2. Найдите «чайник» с главного экрана. Проверьте, что фокус перешёл к каталогу, а поиск оставил нужный материал. Проверьте пустую выдачу и фильтр категории.
3. Переключите тему, увеличьте текст и обновите страницу. Проверьте настройки и читаемость на узком экране.
4. Откройте урок, запустите и остановите озвучивание. Проверьте ручной ввод при запрете доступа к микрофону.
5. Проверьте форму с пустым запросом, текстом и тестовым фото.

Цель по контрасту — минимум 7:1 для основного текста. Полное соответствие WCAG 2.1 AAA требует отдельного аудита. Для ручной проверки предусмотрены NVDA и JAWS в Windows, VoiceOver на устройствах Apple и TalkBack на Android.
