# Голос и звук

«Голос и звук» — прототип справочника по экранному доступу. На главной можно сразу выбрать Windows, iPhone или Android. Для каждой системы есть отдельная страница с пошаговой инструкцией и ссылкой на справку производителя.

[Публичная версия на GitHub Pages](https://andrey101-26.github.io/101-/) показывает статические инструкции. После изменения текста или шаблона пересоберите `index.html` и страницы в `guides/` командой `python app.py --build-static` и добавьте их в коммит.

## Запуск прототипа

1. Запустите `python app.py` в папке проекта. Подойдёт Python 3.10 или новее, устанавливать библиотеки не нужно.
2. Откройте [127.0.0.1:8000](http://127.0.0.1:8000/).

Python обрабатывает поиск в локальном режиме и формирует HTML. Браузеру нужны HTML и CSS. Для публикации с серверным поиском нужен хостинг с Python.

## Сценарий для проверки

На телефоне с уже включённым VoiceOver или TalkBack откройте сайт. Найдите ссылку «Включить Экранный диктор в Windows». Откройте инструкцию и выполните шаги на компьютере. Проверьте, что компьютер начал озвучивать элементы и что клавиша Tab переводит фокус к следующей ссылке. Для проверки поиска введите «как включить экранный диктор» и откройте результат.

На компьютере с работающим скринридером проверьте ссылку пропуска в начало основного содержимого, переходы по заголовкам и ссылки на справку производителя. Соответствие WCAG и удобство прохождения сценария требуют отдельной проверки со скринридерами и с незрячими участниками.
