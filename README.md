# Голос и звук

В ветке `zxc` собран прототип справочника по экранному доступу. На главной можно сразу выбрать Windows, iPhone или Android. Для каждой системы есть отдельная страница с пошаговой инструкцией и ссылкой на справку производителя.

## Запуск прототипа

1. Переключитесь на ветку `zxc`.
2. Запустите `python app.py` в папке проекта. Подойдёт Python 3.10 или новее, устанавливать библиотеки не нужно.
3. Откройте [127.0.0.1:8000](http://127.0.0.1:8000/).

Python обрабатывает поиск и формирует HTML. Браузеру нужны только HTML и CSS. Сервер из стандартной библиотеки предназначен для локальной демонстрации. Для размещения этой версии понадобится хостинг с Python, поскольку GitHub Pages раздаёт статические файлы.

## Сценарий для проверки

На телефоне с уже включённым VoiceOver или TalkBack откройте сайт. Найдите ссылку «Включить Экранный диктор в Windows». Откройте инструкцию и выполните шаги на компьютере. Проверьте, что компьютер начал озвучивать элементы и что клавиша Tab переводит фокус к следующей ссылке. Для проверки поиска введите «как включить экранный диктор» и откройте результат.

На компьютере с работающим скринридером проверьте ссылку пропуска в начало основного содержимого, переходы по заголовкам и ссылки на справку производителя. Соответствие WCAG и удобство прохождения сценария требуют отдельной проверки со скринридерами и с незрячими участниками.
