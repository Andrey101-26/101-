# Голос и звук

«Голос и звук» помогает найти инструкцию, прочитать документ, набрать номер или попросить о помощи. На входе можно прослушать или пропустить вступление. «Экстренная помощь» доступна с любой страницы.

[Публичная версия на GitHub Pages](https://andrey101-26.github.io/101-/) публикуется через GitHub Actions при изменениях в `main`. Команда `python app.py --build-static` создаёт папку `dist/` с готовым сайтом. HTML и CSS отправляются на хостинг как результат сборки.

Записи запускаются вручную. Сайт учитывает светлую, тёмную и принудительную цветовую схему системы.

## Управление с клавиатуры

Ctrl + Shift + F2 открывает или закрывает настройки на любой странице.

Tab и Shift + Tab перемещают фокус. Enter открывает ссылку или активирует кнопку. «Озвучить меню» включает речь и навигацию стрелками вверх и вниз. Режим сохраняется в текущей вкладке. Escape прерывает речь. В полях ввода и аудиоплеере стрелки действуют как обычно. В «Настройках» голос и тему можно выбирать стрелками и Enter даже в тишине. Стрелка за пределами группы закрывает настройки. Escape и кнопка «Закрыть настройки» возвращают фокус к заголовку группы. «Продолжить в тишине» возвращает к главному меню без озвучивания.

## Главное из файла

Выберите DOCX, PDF, ODT, RTF, TXT, Markdown или CSV до 8 МБ. Python в браузере извлекает текст и выбирает до трёх фрагментов по повторяющимся словам и подсказкам вроде «важно». Кнопка «Озвучить главное» читает выдержку через синтез речи браузера. Раздел «Прочитать документ целиком» показывает полный извлечённый текст и позволяет озвучить его. Escape останавливает чтение. Сайт не загружает файл на сервер.

Для старого Word .doc сохраните копию в .docx. Для PDF нужны текстовый слой, отсутствие пароля и не более 80 страниц. PDF и RTF читаются библиотеками Python, входящими в сборку. [pypdf](https://pypi.org/project/pypdf/7.1.1/) · [striprtf](https://pypi.org/project/striprtf/0.0.29/)

## Инструкции и помощь

Поиск на странице инструкций понимает запросы по задаче или устройству, например «мелкий текст», «этикетка» или «диктор Windows». Раздел «Попросить о помощи» объясняет, как обратиться к волонтёру через Be My Eyes, и составляет сообщение с просьбой прислать доступный документ. Сайт подготавливает текст для копирования.

## Звонки

«Экстренная помощь» показывает номера 112 и 101–104 для России. «Набрать номер» позволяет ввести и проверить номер, затем открыть его в приложении для звонков. Для открытия ссылки tel: на устройстве должно быть приложение, которое её поддерживает. [МЧС России](https://60.mchs.gov.ru/deyatelnost/press-centr/novosti/5827639)

## Записать свой голос

На страницах вступления и выпусков есть готовые тексты. Запишите каждый текст отдельным файлом. Подойдут MP3, M4A и WAV. Например, для MP3 используйте такие имена:

- `audio/intro.mp3` — вступление.
- `audio/etiketka.mp3` — «Прочитать мелкую надпись».
- `audio/windows-tab.mp3` — «Перейти к нужной ссылке без мыши».
- `audio/iphone-gesture.mp3` — «Открыть выбранный пункт с VoiceOver».

Храните по одному авторскому файлу на выпуск. Пока авторская запись для первого выпуска отсутствует, на странице доступен синтетический образец с подписью.

## Запуск прототипа

1. Запустите `python app.py` в папке проекта. Подойдёт Python 3.10 или новее, устанавливать библиотеки не нужно.
2. Откройте [127.0.0.1:8000](http://127.0.0.1:8000/).

Python обрабатывает поиск в локальном режиме и формирует HTML. Браузер выполняет `keyboard.py` через PyScript и Pyodide, которые загружаются из сети. HTML и CSS отвечают за разметку и оформление. Если среда Python в браузере не загрузилась, доступны стандартные Tab, Shift + Tab и Enter. Для публикации с серверным поиском нужен хостинг с Python.

Разметка и стили для сборки находятся в `presentation.py`. В Git хранятся исходники на Python, аудиозаписи, документация и конфигурация публикации. Сборка `dist/` создаётся отдельно.

## Сценарий для проверки

На телефоне с уже включённым VoiceOver или TalkBack откройте сайт. Найдите ссылку «Как включить Экранный диктор в Windows». Откройте инструкцию и выполните шаги на компьютере. Проверьте, что компьютер начал озвучивать элементы и что клавиша Tab переводит фокус к следующей ссылке. Для проверки поиска введите «как включить экранный диктор» и откройте результат.

На компьютере с работающим скринридером проверьте ссылку пропуска в начало основного содержимого, переходы по заголовкам и ссылки на справку производителя. Соответствие WCAG и удобство прохождения сценария требуют отдельной проверки со скринридерами и с незрячими участниками.
